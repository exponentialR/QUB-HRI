UL/UR pilot reference labels

This local page displays and edits reference labels. Existing draft provenance and ambiguity flags appear below the image. Check visible hands and selected joints before marking a frame reviewed. Saved manual hand labels include the reference image hash; they remain subject to independent validation.

  1. The seated person is participant. A hand entering from the assisting person, often in a black glove, is other_actor.
  2. For each visible hand, click Add hand, choose its actor and occlusion, then drag a hand box around the visible hand. Use the point tools only for joints you can actually see. If no hand is visible, leave the hand list empty.
  3. To save a hand-only correction, check I checked every visible hand and click Save hand draft. You can leave body and face untouched.
  4. For a complete reference frame later, set face visibility and mark clearly visible participant upper-body points and face anchors. Check all three review boxes, then click Save / mark reviewed.
